Documentação do Vitrola

Um bot de música para Discord com painel web: busca, fila com autoplay, playlists e uma Cápsula do tempo mensal. Cada pessoa roda o próprio bot no próprio computador, sem servidor central.

Pronto para começar?

1 Baixe o projeto. Pelo botão Code → Download ZIP no GitHub, ou com o Git:

git clone https://github.com/ismash1598/Vitrola.git

2 No Windows, dê dois cliques em Iniciar.bat. Ele instala o que faltar e abre uma tela de configuração no navegador.

Quer ver antes de instalar?

A demonstração roda inteira no navegador, com músicas fictícias, sem login e sem instalar nada.

Explore por assunto

Instalação rápidaDo download à primeira música no Windows. PainelBuscar, fila, autoplay e controles do player. PlaylistsPrivadas, do servidor ou públicas. Cápsula do tempoA retrospectiva mensal do que se ouviu. SpotifyBusca mais precisa e importação de playlists. APIRotas REST usadas pelo painel.

O que você precisa

  • Windows 10 ou 11 (para o instalador fácil), internet e uma conta no Discord.
  • Um servidor do Discord onde você possa convidar o bot.
  • Opcional: chaves do Spotify, para uma busca mais precisa.

Instalação rápida (Windows)

O instalador resolve o que faltar, inclusive o Node.js. Você só precisa de internet e de uma conta no Discord.

  1. Baixe o projeto: botão verde Code → Download ZIP no GitHub, e extraia a pasta.
  2. Dê dois cliques em Iniciar.bat. Na primeira vez ele instala o que falta e baixa as dependências, o que pode levar alguns minutos. Se ele pedir para fechar e abrir de novo depois de instalar o Node.js, abra o Iniciar.bat outra vez.
  3. O navegador abre sozinho numa tela de configuração. Siga o passo a passo dela (veja Tela de configuração).
  4. Clique em Convidar o bot para o meu servidor, escolha o servidor e autorize.
  5. Clique em Abrir o Vitrola, entre com o Discord, escolha o servidor e a música. O bot entra no canal de voz onde você estiver.
Importante

Deixe a janela preta do Iniciar.bat aberta enquanto estiver usando. Se você a fechar, o bot desliga.

Nas próximas vezes é só abrir o Iniciar.bat de novo; nada precisa ser configurado outra vez. Para trocar o token, ligar o Spotify depois ou mudar qualquer coisa, abra o Configurar.bat.

Tela de configuração

Na primeira execução, o Vitrola abre uma tela que grava o arquivo .env para você. Estes são os campos pedidos.

CampoOnde pegar
Token do botDiscord Developer Portal → New Application → Bot → Reset Token
Client IDPreenchido sozinho quando o token for válido (ou OAuth2 → General)
Client SecretOAuth2 → Reset Secret (é diferente do token do bot)
RedirectOAuth2 → Redirects → Add Redirect, colando o endereço que a própria tela mostra
Dica

Não precisa ligar nenhum "Privileged Intent". O token e o secret ficam só no arquivo .env do seu computador; ele nunca vai para o GitHub.

Trocar a configuração depois

Abra o Configurar.bat. Ele reabre a mesma tela. Campos em branco mantêm o valor atual.

Preenchendo à mão

Se preferir, copie o .env.example para .env e preencha os valores.

Buscar, fila e player

O painel controla o bot pelo navegador, sem comandos para decorar.

Buscar

Pesquise por nome ou artista. Em cada resultado dá para tocar agora, adicionar à fila ou adicionar a uma playlist.

Fila

Veja a música atual e as próximas. Remova faixas, reordene arrastando e ligue o autoplay: quando a fila acaba, o bot continua com músicas parecidas, usando o Mix do YouTube.

Player

A barra fixa embaixo tem play/pause, anterior, próxima, embaralhar, repetir, barra de progresso e volume.

Compartilhar

Gera uma imagem vertical da música que está tocando.

Configurações (⚙)

Conta, servidor ativo e volume.

Playlists

Organize as suas músicas e decida quem pode ver e tocar cada playlist.

TipoQuem pode ver e tocar
PrivadaSó você.
ServidorOs membros do servidor onde ela foi criada.
PúblicaQualquer usuário logado.

Só o dono edita uma playlist.

Importar por link

Cole o link de uma playlist do Spotify ou do YouTube Music. A importação do Spotify funciona mesmo sem chaves configuradas.

Cápsula do tempo

Uma retrospectiva mensal do que o servidor (ou só você) ouviu, no estilo das retrospectivas de fim de ano.

  • Alterne entre Do servidor e Pessoal.
  • Veja minutos ouvidos, músicas tocadas e artistas diferentes.
  • Ranking dos artistas mais ouvidos e navegação pelos meses anteriores.
  • Um cartão para compartilhar como imagem.

Os dados vêm do histórico de reprodução, guardado em arquivos locais na pasta data/ do seu computador.

Ouvir no site

Um player independente do Discord, que toca no próprio navegador.

Depois de entrar, o Vitrola pergunta Como você quer ouvir?

ModoO que faz
Ouvir no sitePlayer direto no navegador, sem precisar entrar em canal de voz nenhum.
Ouvir no DiscordControla o bot tocando no canal de voz de um dos seus servidores.

Spotify (opcional)

A busca funciona de dois jeitos. Sem as chaves do Spotify, o Vitrola usa o YouTube Music automaticamente.

SpotifyYouTube Music
ResultadosMais precisos: capa, artista e duração certinhosBons, mas às vezes vêm versões ou vídeos errados, sem duração
Precisa configurarSim, com chaves de APINão

O áudio sempre vem do YouTube; o Spotify serve só para a busca.

Ligar a busca pelo Spotify

  1. Entre em developer.spotify.com/dashboard e clique em Create app.
  2. Dê um nome e uma descrição quaisquer. Em Redirect URI coloque http://127.0.0.1:3000 (não é usado de verdade) e marque Web API.
  3. Abra o app criado → Settings. Copie o Client ID e, em View client secret, o Client Secret.
  4. Abra o Configurar.bat, cole os dois na seção "Spotify" e salve.
Importante

Atualmente o Spotify só libera a busca por API se a conta que criou o app tiver Spotify Premium ativo. Sem Premium a busca responde erro 403 e o Vitrola cai no YouTube Music sozinho. Se você assinar o Premium depois, pode levar algumas horas para liberar; não precisa mexer em mais nada.

Amigos de outro computador

Por padrão o painel só abre no computador onde o bot roda (http://localhost:3000). Para os amigos abrirem no navegador deles, você precisa de um endereço público.

O jeito mais simples é um túnel gratuito da Cloudflare:

  1. Instale o cloudflared, no PowerShell: 
    winget install Cloudflare.cloudflared
  2. Com o bot rodando, em outro terminal: 
    cloudflared tunnel --url http://localhost:3000
  3. Ele mostra um endereço https://alguma-coisa.trycloudflare.com. Abra o Configurar.bat, cole esse endereço em "Seus amigos entram de outro computador?" e salve.
  4. No Developer Portal, em OAuth2 → Redirects, adicione o novo redirect que a tela de configuração mostra.
Atenção

Esse endereço muda toda vez que o túnel é reiniciado; nesse caso repita os passos 3 e 4. Para um endereço fixo, use um Cloudflare Tunnel nomeado com um domínio seu.

Quem só quer ouvir música no Discord não precisa do painel: o painel é só para quem controla o bot.

Hospedagem 24/7

Quem quer o bot sempre ligado pode usar uma máquina que fique ligada, como um VPS, com o pm2.

npm install -g pm2
pm2 start src/index.js --name vitrola
pm2 save
Observação

O YouTube costuma bloquear o yt-dlp em IPs de datacenter. Em casa isso quase não acontece.

App Android

O painel em public/ é estático e pode ser empacotado como .apk com o Capacitor.

npx cap add android
npx cap sync android
cd android && gradlew assembleDebug

Dentro do app, abra as Configurações (⚙) e cole a URL do backend. Ela aparece só no app, não no site.

API

Tudo em /api, exceto /api/search e /api/public-stats (públicas), exige o header x-session-token.

MétodoRotaFunção
GET/auth/discord/login · /callbackLogin OAuth do Discord
GET/api/me · /api/guildsUsuário logado · servidores em comum com o bot
GET/api/search?q=Busca músicas (Spotify se configurado, senão YouTube Music)
GET/api/status?guildId=Estado do servidor: faixa, tempo, fila, volume, autoplay
POST/DELETE/api/queueAdiciona / limpa a fila
POST/api/pause · /resume · /skip · /seek · /volume · /autoplayControles
GET/POST/PATCH/DELETE/api/playlists[/:id]Playlists, com visibilidade
GET/api/retrospective?guildId=&scope=&month=Cápsula do tempo

Como funciona por dentro

Os princípios por trás do player, do áudio, do login e da segurança.

Um player por servidor

Cada servidor tem o próprio player (guildPlayers.js), com fila, seek, volume e autoplay independentes.

Áudio

O yt-dlp resolve a URL do áudio e o ffmpeg a envia ao Discord como Opus. Quando o volume é 100% e a fonte já é Opus, o áudio só é remuxado (-c:a copy), sem recodificar, o que reduz bastante o uso de CPU.

Login

OAuth2 do Discord com escopo mínimo (identify guilds). As sessões usam um token opaco no header x-session-token, nunca em cookie.

Segurança

  • Isolamento por servidor.
  • Checagem de permissão em cada rota.
  • Listas de permissão ao receber faixas do cliente.
  • Tickets de uso único para o áudio no navegador.

Persistência e testes

Arquivos JSON (lowdb) com escrita atômica, em data/ (fora do git). Os testes usam o node --test, sem dependências extras.

Problemas comuns

As soluções para os tropeços mais frequentes.

"Invalid OAuth2 redirect_uri" ao entrar com o Discord

O endereço do Redirect no Developer Portal precisa ser exatamente o que a tela de configuração mostrou. Se mudou o endereço público, adicione o novo.

O bot não entra no canal de voz

Confira se ele foi convidado com as permissões Connect, Speak e View Channels (o link da tela de configuração já pede isso) e se você está em um canal de voz.

A música não toca / erro do YouTube

O YouTube muda com frequência e versões velhas do yt-dlp quebram. O Iniciar.bat já atualiza o yt-dlp a cada abertura: basta fechar e abrir de novo.

A porta 3000 está ocupada

Adicione PORT=3001 (ou outra) no arquivo .env, ou feche o programa que usa a porta.

A janela fechou sozinha / quero ver o erro

Abra o Iniciar.bat pelo terminal (cmd) para a mensagem ficar na tela.

Para desenvolvedores

Também dá para rodar sem o .bat, em qualquer sistema com Node.js 18 ou mais novo.

npm install
npm start          # sem .env completo, abre a tela de configuração
npm run dev        # reinicia sozinho ao editar
npm test           # testes automatizados

O .env pode ser preenchido à mão, a partir do .env.example.

Site de demonstração

O front-end é estático, então dá para publicá-lo sem backend. Foi assim que esta demonstração foi feita.

A pasta demo/ tem um demo.js que é carregado antes do app.js e responde as chamadas /api/* dentro do navegador: login simulado, catálogo fictício, player simulado e áudio sintetizado pela Web Audio. O tour.js é o tutorial guiado, que destaca o botão certo em cada passo.

npm run demo:build   # gera dist-demo/
npm run demo:serve   # gera e abre em http://localhost:8080

Para publicar no seu fork: deixe o repositório público, vá em Settings → Pages → Build and deployment → Source: GitHub Actions e dê um push na main.

Uso responsável

Leia antes de hospedar ou distribuir.

Projeto educacional

Tocar áudio extraído do YouTube em um servidor de Discord pessoal, sem fins comerciais, é prática comum entre bots caseiros, mas não é permitido pelos termos de uso do YouTube. Projetos assim já foram derrubados no passado (o bot Rythm, por exemplo, foi desligado em 2021).

Use por sua conta e risco, apenas com amigos, e não o venda nem ofereça como serviço. Não há afiliação com Discord, YouTube ou Spotify.
